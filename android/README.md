# Krouchi_DZ — تطبيق Android (الإصدار الثالث، 3.0)

رفيق الهاتف لبرنامج Krouchi_DZ المكتبي — شيفرة أصلية، بنفس خطّ البناء
اليدوي لتطبيق Raqmana_Fetch_DZ_Android (بلا Gradle).

## ماذا يفعل؟

وضعان: مستقل على الهاتف، ومرافق للحاسوب.

### الوضع المستقل

- **🔑 إدخال API** (الشاشة الأولى): عنوان أساس + مفتاح (+ اسم اختياري)
  ← «اجلب النماذج» يطبّع العنوان (مرآة `discovery.py`: بلا مخطط،
  بشرطة أخيرة، بـ`/v1` أو دونها، بل بلصق `.../chat/completions`)
  ثم يجلب النماذج بـ `GET {base}/models` — وأخطاء مميّزة
  (401 مفتاح مرفوض / خادم لا يُبلَغ / قائمة فارغة…). المزوّد الفاشل
  اكتشافه يبقى محفوظاً مُعلَّماً «غير مُتحقَّق».
- **🤖 البوتات**: إنشاء بوت (اسم، مزوّد، نموذج من المكتشفة، تعليمات
  نظام) محفوظ محلياً على الهاتف.
- **💬 المحادثة**: إرسال إلى `POST {base}/chat/completions` مع ذاكرة
  محادثة لكل بوت محفوظة على الهاتف. لا أدوات ملفات ولا أوامر
  على الهاتف نفسه.

### الوضع المرافق للحاسوب (منذ 2.0)

- **🖥️ الحاسوب**: عنوان الحاسوب + منفذ (افتراضي 8765) + رمز اقتران،
  تُحفظ في تخزين التطبيق. «اتصال» يختبر `GET /api/ping` ويعرض الحالة.
  العقد مع الخادم المكتبي: `http://<pc>:8765` وترويسة
  `X-Krouchi-Token` على كل طلب.
- **بوتات الحاسوب**: قائمة من `GET /api/bots` (مُعلَّمة بأنها بوتات
  الحاسوب)، والنقر على بوت يفتح محادثة تحمل سجلّها من
  `GET /api/history?bot=<id>` وترسل عبر `POST /api/chat`
  (بمهلة قراءة 170 ثانية — الردّ قد ينتظر موافقة على الحاسوب).
- **الموافقات**: استطلاع `GET /api/approvals` كل 4 ثوانٍ أثناء ظهور
  التبويب؛ كل طلب معلّق يظهر ببطاقة (البوت، الأداة، الملخص) مع
  زرَّي «موافقة» / «رفض» يرسلان `POST /api/approvals/<id>`.

### تعدّد اللغات (جديد في 3.0)

- الواجهة بلغتين: **العربية** (الأصل والافتراضي) و**English**.
- مفتاح لغة في رأس الصفحة (ومرآة له في تبويب «حول»):
  اختيار «العربية / English» يُطبَّق فوراً على كل النصوص —
  الثابتة والديناميكية (حالات، أخطاء، بطاقات موافقة، شارات وضع) —
  ويقلب اتجاه الواجهة (RTL للعربية، LTR للإنجليزية).
- الاختيار محفوظ في تخزين التطبيق (`krouchi.lang.v1`) ويُستعاد
  عند كل تشغيل. كل النصوص تمرّ عبر جدول `STRINGS` ودالة `t()`
  في `assets/app.js`، بتكافؤ كامل للمفاتيح بين اللغتين.

البنية: نشاط Java واحد (`dz.krouchi.app.MainActivity`) يستضيف واجهة
HTML/JS من الأصول عبر `https://krouchi.local/` ويقدّم جسر HTTP أصيلاً
(HttpURLConnection — بصيغة مهلة ممتدة اختيارية لطلبات الحاسوب
الطويلة) فلا قيود CORS. الواجهة والمنطق في
`assets/index.html` و`assets/app.js`.

## البناء

```bash
cd Krouchi_DZ/android
node tests_app.js     # 59 اختبار وحدة (23 قائمة + 27 للوضع المرافق + 9 للغات)
./build.sh            # javac ← d8 ← aapt2 ← zip ← zipalign ← apksigner
```

- بيئة البناء: Temurin JDK 17 في `~/workspace/tools/jdk` (d8 في
  build-tools 34 ينهار تحت JDK 21) + Android SDK 34 في
  `~/workspace/tools/android-sdk`.
- التوقيع: `debug.keystore` المحلي (يُولَّد عند أول بناء) — نفس مفتاح
  الإصدارين 0.1.0 و2.0، فيُثبَّت 3.0 فوقه تحديثاً في المكان.
- **درس Raqmana v1.0.7**: `resources.arsc` تُخزَّن في الحزمة
  **غير مضغوطة (STORED)** ومحاذاة لـ 4 بايتات — سكربت البناء يفرض
  ذلك ويتحقق منه، وإلا رفضت أجهزة مثل OPPO التثبيت.
